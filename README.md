# PDF Coordinate Picker

A visual tool for picking and exporting PDF coordinates with multiple origin systems.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Features

| Feature | Description |
|---|---|
| PDF Upload | Drag & drop or click to upload PDF files |
| Coordinate Picking | Click on PDF to capture coordinates |
| Origin Systems | Bottom-Left (pdf-lib), Top-Left (Screen), Bottom-Right, Top-Right |
| Multi-page | Navigate between PDF pages |
| Zoom | Zoom in/out on PDF |
| Grid Overlay | Toggle grid overlay for alignment |
| Coordinate List | View, select, and manage picked coordinates |
| Undo | Undo last picked coordinate |
| Export | Download coordinates as JSON |
